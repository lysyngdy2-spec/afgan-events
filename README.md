# Afgan S&L

ניהול אירועים ל-Afgan Sound & Light: אירועים, צוות, מפרט ציוד לפי המחסן, ספקים חיצוניים וכספים (רק למנהל).

- Next.js 15 + Supabase (Auth עם גוגל, Postgres עם Row Level Security)
- מותקן למסך הבית כ-PWA
- הסכמה וההרשאות: `supabase/migrations/`
- מאגר הציוד: `lib/catalog.json`

משתני סביבה: ראו `.env.example`.
